# swiggy-sales-analysis
Swiggy Sales Analysis is a data analytics project that explores food delivery order data to identify sales trends, customer behavior, and regional performance. Using Python libraries like Pandas, Matplotlib, and Seaborn, the project analyzes KPIs such as total sales, order volume, ratings, and category-wise revenue.

This project performs exploratory data analysis on Swiggy food delivery data to understand order trends, revenue patterns, and customer behavior.

Tools Used
Python
Pandas
Matplotlib
Seaborn
Google Colab

Analysis Performed
- Monthly sales trend
- Daily order distribution
- Top cities by revenue
- Veg vs Non-Veg sales comparison
- Customer ratings analysis
